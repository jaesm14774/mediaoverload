Personal media automation

MediaOverload

MediaOverload is a locally run tool for generating, reviewing, and publishing short-form media. It is used by its owner for personal development and content workflows.

YouTube access

When the owner explicitly authorizes a YouTube account and chooses to publish, MediaOverload uses the YouTube Data API to upload a video and its title, description, and selected visibility setting. It does not operate a public multi-user service.
