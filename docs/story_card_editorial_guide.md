# 從新聞寫出有感情的字稿

一篇值得停下來讀的字卡，要讓人看見原先沒有看見的處境：有人付出了什麼、害怕失去什麼、能不能選擇，以及我們是否太快下了判斷。

讀完之後，可以心疼，可以不安，可以感到被理解，也可以對一個問題有了更深的疑問。溫暖是認真理解人的生活；每則新聞不必以安慰收場。

這份指南用於 MediaOverload 的新聞字卡。它提供選題、文風、鋪墊、反轉、回扣與驗收方法。分類和組合是本專案的編輯方法，沒有研究能保證套用後必然感動讀者。

## 一張字卡由什麼組成

- **字**：1–7 頁繁體中文（使用者全文最多 10 頁），多頁時每頁 50–120 字、最多 4 段，目標 60–100 字：兩到四句完整的話，是寫滿的一個小步驟，不是一句標語；最後一頁的回扣可以只是一個畫面或一個問題，下限減半（25 字）。分段只在意思真的換了一拍的地方，預設一頁一段，不一句一段。由 Pillow 排印在奶油色紙張上，頁面底部置中有「01 / 06」式的頁碼。字永遠是主角。
- **畫布**：字卡有自己的 4:5 直式畫布（角色包 `story_card.canvas`，kirby 為 864×1080），不借用整輪隨機抽到的橫式或方形畫布。字卡是用來讀的，橫式 640×360 只放得下一行標語，是「每頁字數過少、分段很怪」的結構原因。參考作家的貼文同樣是 1080×1356 直式，每張約 55–95 字。命令列 `--width/--height` 仍可明確覆蓋。
- **圖**：每頁各有自己的小插畫（vignette）：選定角色一隻，小小地做「這一頁文字裡的那個物件或動作」，圖要對得上字——頁面談一個詞或想法，就畫代表它的實物（「跨」畫一座小橋），不畫字，也不出現第二隻生物；邊緣像水彩一樣融進紙張，貼在該頁下方。物件、構圖與光線逐頁不同，翻頁時看得到變化；不是每頁同一張，也不是全幅背景加半透明遮罩。每頁的 `scene` 由寫作者隨文字一起交出，GPU 渲染次數等於頁數。
- **頁數**：由來源證據決定，寧少勿湊。只有標題 1–3 頁，有摘要 3–5 頁，有正文節錄 4–7 頁，使用者提供全文 1–10 頁。一個想法不該被拆成兩張卡，頁數太多會讓每頁變薄。頁數上限 10 來自發佈端：Instagram 輪播與 Discord 附件都最多 10 項。角色包設定 `story_card.page_count` 為整數時，頁數固定。證據越薄，故事越短；不為了拉長而補事實。

## 來源與寫作的邊界

新聞是門，不是整間屋子。只把新聞複述一遍的字卡沒有意思；整篇都在評論當事人的字卡也沒有意思。字卡要從新聞裡一個不起眼的細節，走到一個關於人與生活的真道理，再回到那個細節。

來源包含資料庫實際提供的 `content` 與 `article_url`，但正文欄位可能只是節錄。只有標題時，不補造人物遭遇、心理、政策成效或未報導的後果。

**新聞事實只用來源明載的；比方是比方。** 作者的力量來自真實發生過的生活，我們沒有這樣的材料，也不能偽造。能誠實做到的是：新聞提供一個細節，作者用一個「想像……」「就像……」「有些人……」的日常比方，讓一個道理被感覺到。比方用「你」或泛稱，不具名，不寫成真的發生過；它屬於寫作者，不屬於新聞。

仍然禁止的是：寫當事人的感受、動機或真不真心（例如「他是真心關注球隊」），替任何人背書或批評，自編人物對話。只有來源明載的引述可以直接引用。政治、司法、災難、死傷、企業與投資題材，洞見只談人的共通處境，不站在任何一方。來源寫「宣稱、疑似、可能、調查中、預計」，正文要保留同樣的不確定程度。

## 溫暖敘事的機制：鋪墊、洞見、比方、反轉、回扣

這些是從一批長篇溫暖故事貼文歸納出的寫作機制。我們借的是機制，不是情節、物件、對話或句型，也不複製任何原文。那些貼文有長篇的真實生活做底；新聞字卡的底是「洞見」與「比方」。

| 機制 | 做什麼 | 在新聞字卡裡怎麼落地 |
|---|---|---|
| 鋪墊（planted detail） | 第一頁放進一個不起眼的具體細節，讀者當下不覺得重要 | 取自來源的一個次數、順序、時間點、動作或物件，例如「第二次」「連續」「最後一個」；用自己的話描述，必須在來源找得到 |
| 洞見（insight） | 一句換掉這則新聞也成立的、關於人的真道理 | 重複才算數；沒入鏡的那一邊；代價落在誰身上；小動作比大話誠實；反向因果。用場景說，不用「人生就像」式的格言說 |
| 比方（parable） | 一個普通人都經歷過的日常小畫面，讓洞見被感覺到 | 「想像你有一件穿到起毛球的毛衣……」。物件、動作、時間、數字要具體；佔全篇最多頁數；明講是比方 |
| 反轉（turn） | 約在六成處，讀者原本的理解被一個細節翻過來 | 「原本以為……，直到想到比方裡的某個動作，才發現……」；被翻轉的是對那個細節的理解，不是對當事人內心的判斷 |
| 回扣（echo） | 最後一頁回到鋪墊的細節，讓它因洞見換了意思，然後停下 | 具體的事，不是口號；不寫總結、不勸世 |

另外四條共同做法：

1. 第一頁就擺出讀者的預設想法，並讓它看起來合理，後面才有東西可翻。
2. 中段每頁只推進一小步，後一頁使前一頁更具體或更複雜；任意交換頁序仍成立，就是在湊字。
3. 用動作與細節說感受。一篇最多用一個直接的情緒詞，不用形容詞替讀者感動。
4. 結尾停在一個畫面或動作上。道理已經在前文說完，再說一次會把它弄小。

一個虛構的標題示範（只為說明結構，不是素材）：「某老麵包店開業滿三十年，週日門口仍有人排隊」。鋪墊是「三十年後還排在同一條隊伍」；洞見是「人留戀的常常不是最好的，是明天還在的」；比方是「想像你有一件穿到起毛球的毛衣，你不是不知道可以買新的，只是它每年冬天都在」；反轉是原本以為排隊是為了好吃，想到那件毛衣才發現排的是「它還在」；回扣是最後回到那條隊伍。全篇沒有編出店員或客人，也沒有編出任何台詞。

### 為什麼這樣改：一次真實產出的教訓

有一次產出把「市長到場看球賽」寫成五頁，每頁都在重述新聞。規劃步驟挑了「第2戰」當鋪墊，卻漏掉來源更有重量的「這是他第2次來」；它的「反轉」是「讀者以為是政治宣傳，其實他是真心關注」，那是替真人猜心思，也不是來源說的。寫作提示又禁止一切想像，寫手只剩改寫新聞這一條路。所以現在規劃要先找出洞見與比方，並禁止判斷當事人真心；寫作者獲准用被框起來的比方承載道理。

## 寫作之前的判斷

### 1. 事件：究竟知道什麼

用一句平實的話記下誰做了什麼，以及來源確實說到的變化。另列不知道的事。資料應分清：

| 手上資料 | 可以做的事 | 不能補成事實的內容 |
|---|---|---|
| 只有標題 | 針對標題提出的問題作有限反思，自然交代「標題提到」 | 未讀到的引言、細節、原因、心理或結果 |
| 有摘要 | 以摘要明載的事實與限制為範圍 | 摘要略過的經過、完整爭議與代表性 |
| 有全文或來源節錄 | 選取足以支撐觀點的細節，保留引述者與不確定性 | 未受訪的內心、合成人物、裝成親身經歷的回憶 |
| 有網址 | 保留來源供查核；取得內容後才能使用正文資訊 | 把「知道網址」當成「讀過全文」 |

關鍵字用來找方向，不能證明事件發生。「疑似」「計畫」「受訪者認為」都不能在修稿時消失。題目本身帶問號時，也不能把假設改成已證實的答案。

### 2. 本質：找出需要與代價

不要只填「人性、愛、恐懼」。把問題寫完整：

- 誰希望保住什麼？工作、尊嚴、家人的安穩、拒絕的權利，還是被需要的感覺？
- 他能選擇嗎？選項受金錢、時間、權力、健康或照護責任限制嗎？
- 看起來成功的決定，誰在承擔不容易被算進去的代價？
- 兩個願望能不能同時成立？想陪家人，也想休息；喜歡便利，也在意自主。

每篇只挑一個主要矛盾。找不到時，回到來源，不要用抽象名詞湊滿欄位。

### 3. 情緒：決定讀者的理解怎麼移動

情緒的變化要能用前後差異描述。例如：從「怎麼連這也做不到」到「原來他的選項比我少」；從「又一項技術更新」到「提前準備也是替別人留餘地」。這個前後差異，就是反轉要翻的那一面。

可用的複合情緒包括心疼中的尊重、鬆一口氣後的內疚、佩服裡的不安、替人高興卻也看見他的代價、失望後仍願意理解。不要每篇都把情緒推到最滿。寫災難時，克制比煽情更能讓當事人的處境留在讀者心裡。

### 4. 文風：根據矛盾選聲音

文風是表達手段。先有值得說的事，才選擇溫柔、尖銳、沉靜或帶一點幽默的聲音。

## 新聞大分類與文風指引

| 新聞類型 | 優先找的人性問題 | 常適合的文風 | 鋪陳方式 | 最容易寫壞的地方 |
|---|---|---|---|---|
| 財經、股市、投資 | 安全感、害怕落後、不同的風險承受能力 | 反思、清醒共感 | 數字變化 → 不同人的處境 → 同一結果的不同代價 | 把投資人一律寫成貪婪，或暗示漲跌能定義人生 |
| 就業、裁員、職場 | 專業認同、被需要、可替代感、生活安排 | 感性、反思、有限的鼓勵 | 已知決策 → 人失去或保留的選擇 → 評價工作的另一個角度 | 虛構被裁者流淚收紙箱，催人感謝挫折 |
| 創業、商業成敗 | 想證明自己、責任、放棄與承諾的衝突 | 勵志、苦甜、深思 | 目標 → 付出的代價 → 有限制的選擇 | 只寫堅持就能成功，略去資源與運氣 |
| 科技、AI、資安 | 便利、自主、信任、替代、事前承擔 | 深層思考、帶溫度的反思 | 技術決策 → 生活裡誰依賴它 → 被忽略的責任 | 宣告時代浪潮，或把所有技術都換成父母的愛 |
| 科學、探索、太空 | 好奇、未知、耐心、承認不知道 | 驚奇、沉靜深思 | 一項發現 → 原本的理解哪裡改變 → 仍未知的部分 | 誇大發現、把比喻寫成科學結論 |
| 社會、公共政策、房住 | 尊嚴、公平、選擇權、誰被制度漏掉 | 人性反思、溫和或直接的評論 | 制度差異 → 對生活的影響 → 責任或價值判斷 | 只勸個人調整心態，替制度問題安排勵志結局 |
| 國際、戰爭、制裁 | 權力、流動、被迫承受、不同人的出路 | 克制反思、沉重共感 | 已知變化 → 誰能改道、誰不能 → 尚待回答的代價 | 把逃難當旅行，把資金套利寫成溫馨互助 |
| 娛樂、名人、文化 | 被看見與被消費、作品與期待、職業界線 | 感性、反思、欣賞 | 公開行動或作品 → 觀眾的期待 → 看待人的方式 | 替名人腦補孤獨、憂鬱、創傷和私生活 |
| 運動、競賽 | 合作、臨場選擇、努力的限度、輸後如何相待 | 熱血、敬意、苦甜感性 | 具體一刻 → 限制與選擇 → 比勝負多看見的事 | 把受傷硬撐寫成美德，只尊重逆轉與冠軍 |
| 家庭、關係、兩性 | 在乎與控制、依賴與自主、愛與界線 | 感性、療癒、反思 | 關係中的摩擦 → 雙方需要 → 可理解的新界線 | 強迫原諒、把付出變成索取服從的理由 |
| 醫療、長照、身心健康 | 疲憊、尊嚴、求助、不能自己決定的生活 | 共感、照護反思 | 已報導的困難 → 負擔如何分配 → 人的極限被承認 | 診斷當事人、保證康復、歌頌無止境犧牲 |
| 教育、校園、青年 | 被評價、失敗羞恥、期待、試錯空間 | 成長反思、溫柔鼓勵 | 一次判斷 → 被忽略的條件 → 如何重新理解能力 | 空喊每個人都特別，略過具體資源差異 |
| 犯罪、事故、災害 | 失控、信任破裂、責任、漫長後續 | 警醒、哀傷、克制評論 | 已知事件 → 可以確定的影響 → 調查與責任界線 | 未審先判、怪罪受害者、獵奇、替悲劇找禮物 |
| 動物、寵物、環境 | 陪伴、依存、照顧責任、失去棲地或日常 | 療癒、珍惜、憂傷、驚奇 | 可觀察的行動 → 依賴關係 → 責任或珍惜 | 腦補動物台詞，用可愛掩蓋照顧成本 |
| 地方生活、社區、小店 | 歸屬、互相認得、日常服務、消失的關係 | 暖心、懷念、生活反思 | 具體改變 → 原先承載的生活 → 改變之後留下什麼 | 一間店打烊就喊時代終結，捏造常客與店主故事 |

同一則 AI 新聞，焦點若是更方便，可能寫欣喜；若是工作被重新分配，可能寫不安；若是資料怎麼使用，可能寫信任。不可只看分類名稱就分配情緒。

## 六種文風，六種不同的落點

| 文風 | 要讓讀者得到什麼 | 結尾可以落在哪裡 |
|---|---|---|
| 反思 | 發現自己原先的判斷漏了一部分 | 一個有根據的新看法，或尚未被回答的具體問題 |
| 感性 | 某種難以說清的感受被準確說出 | 矛盾的心情、已知動作、改變後的相處方式 |
| 療癒 | 不被責備地理解自己的需要與極限 | 可以休息、求助、保留界線的空間；不承諾一切會好 |
| 勵志、雞湯 | 在真實限制中仍看見一點行動可能 | 可行的小選擇，以及它能做到的範圍 |
| 深層思考 | 看見事件背後的價值衝突與責任分配 | 沒有被簡化掉的兩難；不必假裝有唯一答案 |
| 熱血、警醒 | 在明確事件中感受決定的重量 | 選擇和代價。前者增加力量，後者留下警覺 |

「有感情」不等於每種聲音都要輕柔。談傷害可以生氣，談失敗可以不甘心；只是要清楚，自己在為什麼事、替誰說話。

## 寫一句能留下來的話

有力量的句子往往把事件裡的矛盾說準。要先有前文，讀者才知道這句話為什麼出現在這裡。

| 空泛草稿 | 修稿時應追問 |
|---|---|
| 在科技飛速發展的時代，唯有人性的溫度永遠不變。 | 哪一項技術、改變哪一種選擇、誰受到影響？ |
| 每一次跌倒，都是命運最好的禮物。 | 這次失敗造成什麼損失？當事人有沒有其他選擇？ |
| 那些無聲的守護，終將化為生命中最溫暖的光。 | 誰實際做了什麼？投入和日常之間的關係是什麼？ |
| 願我們都能學會珍惜，成為更好的自己。 | 前面究竟增加了哪一個理解？把那個理解說完就停。 |

不要把去 AI 味變成禁詞遊戲。「但是」「其實」「不是」都有正常用途。問題是整篇是否靠同一個對比句型製造深刻，是否只把一句道理換幾種說法。

朗讀時，要聽見人在思考的節奏。短句能停頓，較長的句子能承接因果。連續碎句、每句都換行、每段都押一個金句，會讓讀者聽見模板。

## 程式如何落實

`agentic/src/agentic/runtime/story_cards.py` 保存寫作原則、頁數規則、格式檢查與 Pillow 排版。`LLMPromptEngine.build_story_card`（定義在 `runtime/prompt_tasks/story_cards.py`）分兩步：

1. **選看點**：只交編輯提要。除了 `evidence_anchor`（指向實際存在的標題、摘要或正文欄位，並用自己的話標示來源訊號），提要要有 `source_limits`、`lens`、`reader_reason`，以及五個敘事承諾：`planted_detail`、`insight`、`parable`、`turn`、`echo`。缺少任何一欄就在寫作前失敗。
2. **寫字卡**：依提要與來源直接寫成完整頁面，只交標題與各頁 `role`（只能是 hook、assumption、parable、turn、echo，最後一頁必須是 echo）、`text`、`scene`（英文，一句話描述該頁的小插畫）。全篇只用一個比方、一件物件，一到兩頁說完；hook 頁可順手帶出讀者的「以為」。頁少時合併步驟，但仍以回扣收尾。頁數範圍依證據決定；寫作 schema 不設字數上限，避免解碼器把句子截成一半，每頁 50–120 字由驗證檢查，過長、過薄時最多三次帶著具體違規原因回到同一個寫作者重新分頁。提示詞不放任何具體的示範物件或示範句，只給帶括號的節奏骨架，因為具體示範會被模型原句抄進正文與插畫。

成品保存 `editorial_brief`、`source_context` 與 `writing_process.plan`，recorder 保留實際輸入輸出。`evidence_anchor` 只能檢查所指欄位確實存在且有非空訊號，不能證明整篇推論正確；語意與情感仍須閱讀。正文必須含中文、不得含 hashtag 或標記，每頁的 `scene`、`vignette_prompt` 與整篇的 `negative_prompt` 只接受英文；缺 `scene` 的頁面會被退回寫作者補上。簡繁檢查只攔常見簡體字，不把「皇后」這類正體用字當錯字。產稿時將模型誤輸出的字面 `\n` 還原為段落換行，再交給人審閱。

規劃圖為 `story-card-write → story-card-image-asset-check → story-card-vignette → story-card-compose`。`story-card-vignette` 對每一頁呼叫一次 `comfy.workflow.text_to_image`（krea2_turbo），各頁使用不同的種子與獨立的輸出資料夾：提示詞由選定角色、角色包的 `story_card.visual`（場景風格、從屬配角）、該頁的 `scene` 與一組正面描述的畫風（單一小幅童書插畫、水彩彩鉛、奶油紙底、邊緣柔化融進紙張、表面不帶任何標記）組成。krea2_turbo 不理會 negative prompt，所以禁止文字等限制以正面措辭寫進提示詞，實際的字只由 Pillow 負責。主角身份只來自 resolved character 與 character profile，不能寫死 Kirby，也不能在選角失敗時 fallback。

`story-card-compose` 先程序化產生奶油紙紋理，每頁再把自己的小插畫以羽化橢圓遮罩與正片疊底貼在紙張下方；插畫張數必須等於頁數。標題只出現在第一頁，正文字級自動縮放（基準 46、最小 28），一律排在插畫上方，不截字。可變字型使用 Regular 字重；常見中文標點避免在自動換行後落到行首。

模型或編輯失敗會回報失敗，沒有忽略新聞而回傳固定故事的 fallback，明確的 template 模式也不冒充字卡生成。選看點與寫作步驟都在原本的人工作品審閱前；人核准後不再多加一次語意或文風 gate。

新聞選擇器讀取資料庫已有的 `content` 和 `article_url`，透過 `NewsSelection` 帶入 `news_context`。來源欄位各最多使用 8,000 字，正文視為提供的節錄；沒有正文時仍只能依標題反思。網址供查核，不會被當成已讀過的全文。

## 人工驗收：先遮住圖片讀一次

| 檢查 | 可以接受的證據 | 需要退回修稿的現象 |
|---|---|---|
| 真實性 | 新聞事實能指出來源，比方被明講是比方，沒有判斷當事人的心意 | 為了動人添了人物、台詞、傷害或結果；說某人「是真心的」 |
| 新聞連結 | 能用一句話說明這篇由哪個事件的哪個細節生出 | 換五則新聞仍然通用 |
| 洞見 | 能用一句話說出讀者帶走的道理，且不是新聞摘要、也不是對當事人的評價 | 整篇只是把新聞換句話說；道理是「珍惜當下」之類的口號 |
| 畫面 | 各頁插畫的物件與構圖不同，各自對應該頁的字 | 每頁看起來是同一張圖 |
| 鋪墊 | 第一頁的細節在最後一頁回來 | 結尾出現前面完全沒有的東西 |
| 反轉 | 讀完能說出「原本以為什麼，後來才發現什麼」 | 全篇只是摘要，或只是情緒配樂 |
| 人的處境 | 說得出誰想保住什麼、被什麼限制 | 只出現「人性」「溫暖」「成長」 |
| 推進 | 後一頁使前一頁更具體、更複雜或更有意義 | 頁序任意交換也沒有差別 |
| 收尾 | 停在畫面或動作上，允許仍有問題 | 突然勸人珍惜、加油、相信未來 |
| 聲音 | 念出來像人願意認真說的話 | 每句都是金句，或像把英文抽象詞翻成中文 |

真實性和新聞連結不成立，就不值得用排版補救。主觀情感由人讀稿判斷；密度、標點與文風是寫作建議，由 Discord 人工審閱。自動 DQ 不因篇幅、句尾形式或重複標題拒絕成品，硬性檢查只保留可排版上限與下限、頁數、欄位、角色順序（最後一頁是 echo）與輸出語言，另有兩條機械式契約：正文不得談論「頁」或「讀者」本身（例如「最後一頁回到……讓讀者開始問自己」是把給寫作者的指示印到了卡上），也不得把編輯提要裡屬於「指示」的欄位（turn、echo、reader_reason、source_limits）原樣貼成正文（連續 16 字以上相同即退回改寫，來源本身用過的標題或引述不算；parable 與 insight 本來就寫成場景與一句話，不在此限）。這些是格式契約，不是以模型評分取捨成品的 QA 關卡。版面是否放得下，在寫作步驟就用當輪畫布尺寸檢查（`ensure_story_card_fits`），放不下的頁面帶著原因回到寫作者縮短，而不是等十張圖都生成之後才在合成階段失敗。`scene` 若寫到紙張、螢幕、標示等會讓影像模型亂寫字的物件，或寫成像指令的句子（如 ignore、follow），驗證都會把整張卡退回寫作者重畫那一頁的 scene；不再默默略過那句描述，因為略過會讓那一頁的圖和字對不上。

## 尚未驗證的邊界

本機測試以 `ScriptedLLMManager` 與假的影像工具覆蓋契約、頁數、規劃圖與排版。文字品質另以只呼叫文字模型的探測腳本在真實的模型池上抽樣檢查（不經 ComfyUI），但那只是單次抽樣，模型池輪替，不能當作品質保證。實際的 LLM 文字品質、krea2_turbo 小插畫的外觀與 ComfyUI 與 GPU 執行，只能在真機生成後由人審閱，不能由單元測試證明。

## 研究依據與延伸閱讀

以下提供寫作方法的依據；新聞分類表與驗收表是本專案綜合設計，並非這些作者提出的分類。

- Roy Peter Clark，具體細節與抽象意義之間的移動：[Writing Tool #13: Show and Tell](https://www.poynter.org/reporting-editing/2004/writing-tool-13-show-and-tell/)。
- Lauren Kessler，人物如何經由可觀察的行動被理解，以及為什麼不能推測當事人的思想：[Character: The beating heart of narrative](https://niemanstoryboard.org/2023/05/11/profiles-character-development-reporting-sources/)。
- Roy Peter Clark，事件的閱讀與意義的理解：[Stories are read twice in readers' minds](https://niemanstoryboard.org/2020/03/11/stories-are-read-twice-once-for-the-literal-story-then-for-the-metaphorical-meaning/)。
- Mark Kramer，非虛構寫作的真實性、聲音、結構與讀者經驗：[Breakable Rules for Literary Journalists](https://niemanstoryboard.org/1995/01/01/breakable-rules-for-literary-journalists/)。小說技法可以協助組織報導，不能因此捏造事實。
- Tom Ehrenfeld 整理 Clark 的寫作工具，涉及長短句、節奏與結尾：[A Sampling of Clark's 50 Writing Tools](https://niemanreports.org/a-sampling-of-clarks-50-writing-tools/)。

來源作品只用於分析一般寫作技巧，不複製作者用語、品牌、辨識度高的情節或完整結構。
